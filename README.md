# Ask the Vibration

Ten common questions about bearing vibration data, answered by listening, guessing and dragging real recordings from the
[Case Western Reserve University Bearing Data Center](https://engineering.case.edu/bearingdatacenter).

Live: https://qwertykeypadapple.github.io/ask-the-vibration/

- `index.html`: the question-by-question site (no build step)
- `data.js`: signals, spectra and facts extracted from the CWRU recordings
- `story.html`: an earlier slideshow version
- `tools/extract.py`: regenerates `data.js`; it needs the Bearing Collective experiment code and the raw `.mat` files, which are not in this repo

Companion to [Bearing Collective](https://qwertykeypadapple.github.io/bearing-collective/).
